# English
Основная цель: Создать мобильное приложение для web, Android и iOS, сначала делаем мобайл,  которое заменяет полноценного репетитора и доводит пользователя до уровня C1 через системный подход, а не просто игрушки. Приложение должно быть коммерчески успешным и реально полезным. Если тебе что-то непонятно, то справшивай меня

### Процесс разработки (workflow):
1. Предлагаю задачу коротко и ёмко
2. Жду одобрения на задачу
3. Предлагаю детальный план реализации
4. Жду проверки плана и корректировок
5. Самостоятельно разрабатываю без дополнительных разрешений
6. Самостоятельно проверяю на ошибки в консоли (с запущенным проектом)
7. Самостоятельно исправляю найденные ошибки
8. Делаю commit и push в GitHub
9. Предлагаю проверить результат
10. Предлагаю следующую задачу
